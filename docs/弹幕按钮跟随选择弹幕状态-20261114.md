# 弹幕按钮跟随“选择弹幕”状态

修复对象是功能栏“弹幕”面板内、紧接“弹幕搜索”的宿主“弹幕”按钮。文字黄色只表示“选择弹幕”中至少一个源被勾选；全部取消、没有源或无法读取对应宿主状态时恢复正常文字颜色。聚焦仍显示边框；取消源时即使按钮仍聚焦也恢复正常聚焦文字颜色。

旧实现直接使用 View.selected/activated 控制黄色。TV 原生 activated 对应独立的 danmu 全局显示开关，而选择页取消当前源执行 Danmaku.empty()，更新源列表各项 isSelected，未清除该 View 标记，因此产生关闭弹幕后文字仍黄的现象。

## 实现

- HostDanmakuSelection 只读取已确认的宿主源列表，不修改源、按钮业务状态或原点击/长按监听。
- T1/516：当前电视 APK 中 VideoActivity 的 C3.e 引擎字段，读取 s 列表。O3.k 选择页从同一列表复制源对象；适配器选择已选项时将 Danmaku.empty() 交给引擎 i0，再更新列表 selected。当前 APK MD5：9ec8e4b8c49e227238b1a3849d2d5623。
- T2/516：归档手机 APK 中 VideoActivity 的 F3.f 引擎字段，读取 s 列表；k0 更新同一列表选择状态。
- T3/556：沿已验证 PlaybackService.z（xe2）→ f（gf0）→ n（List）读取。
- 只在弹幕面板首次创建、既有刷新及窗口焦点归还时同步颜色，状态未变化时不重复设色。主功能栏入口样式保持原规则。
- 保留工具设置/扫码配置关闭后的焦点恢复及 Go 代理 Range 修复。
