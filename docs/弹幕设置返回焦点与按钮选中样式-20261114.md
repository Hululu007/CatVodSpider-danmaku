# 弹幕设置返回焦点与按钮选中样式

本文记录 dialog-focus-r1。其中 selected/activated 控制黄色的方式已被同日后续修复替代：当前颜色跟随“选择弹幕”实际源勾选，详见 [弹幕按钮跟随选择弹幕状态](弹幕按钮跟随选择弹幕状态-20261114.md)。本文的子窗口返回焦点机制继续保留。

从主栏弹幕面板打开工具设置、扫码配置后，面板按钮被移除。原恢复逻辑将播放器的
可聚焦父容器当成有效焦点，导致仍显示的功能栏没有按钮焦点。

ToolbarDialogFocus 记录主栏弹幕入口，子窗口关闭且播放器窗口取得焦点后恢复该入口。
恢复安排在当前消息队列及 60/220 ms；成功即撤销其余回调。嵌套设置窗口还持有焦点时等待
最终归还。功能栏已隐藏、换视频、Activity 暂停/退出、切换面板时取消旧任务。
扫码配置包括返回键及手机打开配置页自动关闭两种方式；工具菜单取消与子页面返回共用此恢复机制。

本次黄色文字样式仅应用于弹幕面板中紧接“弹幕搜索”的原生弹幕按钮。
selected/activated 状态文字为 0xFFFFD54F，不再增加选中背景或暗边框；真正聚焦仍显示焦点框。
宿主的控件实例、点击/长按监听、开关状态保留。主栏弹幕入口使用原样式。
