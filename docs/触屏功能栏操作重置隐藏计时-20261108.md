# 触屏功能栏操作重置隐藏计时

用户确认问题发生在手机/平板：临近宿主自动隐藏时点击新功能栏入口，刚打开的设置面板随旧隐藏任务一起消失。

## 修复

- `PlayerToolbarController` 在 T2/516、T3/556 主栏与设置框的按钮点击、长按、触摸操作前调用宿主原生重置方法。面板滑动 MOVE 最多每 250ms 续时一次。
- T2：`VideoActivity.S0()` → `App.b(r0, r3.a.a)`；T3：`VideoActivity.P1()` → `App.b(l0, 5000)`，保留 P1 的锁定状态判断。两端 `App.b` 都先 removeCallbacks，再 postDelayed 原 Runnable。
- 按包名、Activity、版本、已确认的控件树选择接口，方法只在绑定时反射解析。没有独立隐藏任务、全局触摸/按键拦截或后台续时轮询。
- 原生点击、长按、触摸监听各委托一次；退回旧布局时仅恢复仍由当前会话持有的监听，释放已销毁面板按钮的引用。
- 只在功能栏可见且会话有效时续时；布局刷新不续时；搜索主动隐藏仍优先。TV 保持原遥控与时间轴 OK 暂停/播放逻辑。

## 验证

- Gradle `assembleRelease` 成功。
- Mi Max / Android 10 / 192.168.31.21 上独立 Android 工具：T1、T2、T3 合计 **937 项通过**。T3 加载归档 APK 的真实 LinearLayoutCompat。包含临近到期点击、原生/自定义按钮、长按、面板触摸、最终空闲隐藏、隐藏后不重启计时、搜索主动收屏和既有时间轴操作。
- 手机真实宿主 OK影视 5.1.6：加载试用 JAR 并核对缓存 MD5；播放谷雨第02集。唤栏约 4 秒后点击播放设置，采样时距唤栏 **8.33 秒**、距点击 **3.78 秒**，功能栏与设置面板仍显示；再等待后两者自动隐藏。XML 证据在 `build/toolbar-idle-20261108/mobile-timing.xml`、`mobile-expired.xml`。
- 真实宿主原生循环按钮的第二组采样没有捕获到打开的面板，不计作通过；该次原生动作/采集时序未确定。面板内按钮委托与续时由上述独立回归覆盖。真实平板未验收，不将三端结构回归冒充三台实机通过。
- 手机试用前备份，结束后恢复原订阅与观看数据库，配置三项核对一致；独立测试包已卸载。临时媒体、配置、JAR留在 `/sdcard/idle-*` 供追溯，不影响原订阅。
